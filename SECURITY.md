# Security policy

## Supported versions

Security fixes go into the latest release. Tiki updates itself, so keep it up to date from
Advanced settings › General.

## Report a vulnerability

Do not open a public issue. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/apiservicesac/tiki/security/advisories/new)
or by email to principal@apiservicesac.com.

Please include what is affected, how to reproduce it and the Tiki version. You will get an
answer within a week; once a fix is released, the report is credited unless you prefer not.
